# Use 240 human response labels for live judge calibration

Freeze live judge calibration around 240 human-labeled response rows arranged into 144 blinded absolute bundles, plus 24 pairwise relationships that reuse those responses. This size covers every semantic success and failure class, source stratum, output arm, and domain group without expanding to redundant labels; reversed A/B judge calls reuse the same human relationship labels. The 188 live calls have a $5 all-in ceiling including retries and must use only the official Z.AI GLM-5.3 Flash route, currently exposed as `z-ai/fp8`, with provider fallback disabled. Operational JSON, transport, timeout, and provider failures remain software/replay cases rather than consuming human semantic labels. If live agreement criteria fail, calibration fails closed; any rubric, request, provider, route, or judge change creates a new version and cache namespace rather than silently altering the frozen study.
