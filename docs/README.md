# Docs

This directory contains tracked project notes and human-readable run records.

## Layout

- `handoffs/`: long-form handoffs for future agents or resumed work.
- `lessons/`: explanatory HTML lessons.
- `runs/`: tracked metadata, logs, and postmortems for completed runs.

Large binary outputs stay outside `docs/` in ignored artifact directories such as `artifacts/`.
