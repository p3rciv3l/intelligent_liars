Lesson 1: Intelligent Liars Codebase Structure

This lesson teaches the repository as a system of objects and transformations. The starting object is not "a model" or "a probe." The starting object is a set of files on disk. The code turns those files into prompts, model responses, labels, token masks, hidden-state rows, and later probe-training data.

0. The One-Sentence Map

The repository is a pipeline for taking Truth Spec-style text datasets, running or replaying them through Qwen3-VL, isolating assistant answer-token hidden states, and writing labeled activation rows that can later train truth/deception probes.

Separate these three things immediately:
  • Data files: CSV, YAML, JSON, and HDF5 files stored under data/, references/, and artifacts/.
  • Python objects: dataclasses such as PromptExample, ActivationExample, ProcessorBatch, and DetectionMask.
  • Model computation: Qwen3-VL forward passes or generation calls. These create text or hidden-state tensors, but they are not the labels by themselves.

5. Mechanism Microscope: What Is a Backend?

By "backend," this code does not mean a web server. It means "the mechanism that runs a model and returns hidden states in a common shape." The dataset code should not care whether hidden states came from a PyTorch forward hook or from NNsight tracing.

7. What Changed With FlashAttention-2

The model loading primitive changed in one place and is reused by both model paths.

qwen_model_load_kwargs(cache_dir=...)
  -> {
       "cache_dir": cache_dir,
       "device_map": "auto",
       "dtype": torch.bfloat16,
       "attn_implementation": "flash_attention_2",
     }

This matters because generate-rollouts and generate-insider-trading use load_model_and_processor, while NNsight extraction uses load_nnsight_bundle. If these diverge, generation and activation extraction might run under different numerical/runtime settings. The new helper keeps them aligned.

8. The Mental Model to Keep

Local computation

The code locally reads files, builds Python objects, formats Qwen chat strings, runs model calls, writes JSON/HDF5. This is machinery.

System-level purpose

The research purpose is to find hidden-state directions correlated with truthfulness/deception, then test whether steering can damage reported truth while preserving other capabilities.

Representation vs label

A hidden state is a numeric vector row inside Qwen. A label is an external tag like HONEST=0 or DECEPTIVE=1. Probe training later connects them.

Generation vs extraction

Generation creates the assistant text. Extraction replays prompt+answer through Qwen and captures internal hidden states at answer tokens. Those are different passes.
