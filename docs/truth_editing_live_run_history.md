## Launch checklist

- Confirm no stale Vast instance is still running.
- Confirm the bundle was rebuilt after the latest code or config change; verify its SHA-256.
- Use the pinned Qwen checkpoint, BF16, FlashAttention 2, and the frozen official Z.AI GLM-5.3 Flash route.
- Keep local hashed receipts and checkpoints authoritative.
- Never put secrets in bundles, arguments, configs, logs, receipts, or W&B.
- Require W&B real-canary readback before the 200-trial run, but never let W&B failure change or stop optimization.
- Destroy temporary GPU instances after success or failure and record the lifecycle receipt.
